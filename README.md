# 📺 YouTube Clone – SuperSimpleDev Project

**Built by [@CreativelyNanda](https://github.com/Nanda-Regine)**  
*A clean, beginner-friendly YouTube homepage UI using HTML & CSS*

---

## ✨ Project Overview

This is my first web development project following the SuperSimpleDev course. I recreated a simplified YouTube homepage layout using pure HTML and CSS. The goal was to practice real-world UI structure, responsive design, and layout styling fundamentals—without relying on JavaScript or frameworks.

This project is part of my broader journey into front-end development and creative tech building.

---

## 🔧 Tech Stack

- ✅ **HTML5**
- ✅ **CSS3**
- ✅ **Flexbox & CSS Grid**
- ✅ **Visual Studio Code**

---

## 🎯 Key Learnings

- Structuring semantic and accessible HTML pages
- Mastering the box model, padding, margin, and spacing
- Designing responsive layouts with Flexbox and Grid
- Organizing project files and assets
- Crafting pixel-perfect thumbnails and card elements

---

## 🖼️ Features

- Sidebar navigation (Home, Explore, Subscriptions, etc.)
- Search bar and top nav menu
- Video thumbnail grid layout
- Metadata sections (title, views, uploader)
- Custom thumbnail hover effects
- Mobile-friendly layout (basic responsiveness)
